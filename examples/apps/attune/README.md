# Attune

A responsive front-end concept for a private, live conversation companion. The interface demonstrates speaker-aware transcription, careful tone interpretation, and nonjudgmental coaching prompts for couples navigating difficult conversations.

## Run locally

```bash
cd examples/apps/attune
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Product principles

- Describe emotional signals as possibilities rather than facts.
- Encourage reflection and understanding instead of taking sides.
- Keep pause, mute, and session-ending controls immediately accessible.
- Clearly communicate audio privacy expectations.

This prototype uses sample transcript content and does not capture or send audio.
